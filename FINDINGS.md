# Findings

The results this repository stands on, one row each: what was measured, on how many runs,
what it showed, and where the evidence is. Every row names the DESIGN-LOG section that
carries the full method and the results file the numbers were computed from. A row with no
interval was not a pre-registered comparison; read it as a measurement, not a verdict.

Conventions: "a side" is runs per arm; intervals are 95% bootstrap intervals on the
difference (`bench report --view compare`, `bench/stats.py`); "n.s." means the interval
included zero. Costs are OpenRouter's billed dollars.
